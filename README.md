# DaisyUI Nuxt Application

![DaisyUI Nuxt](https://raw.githubusercontent.com/ruanvalente/daisy-ui-nuxt/main/public/preview.png)

## About the Project

Este projeto é uma aplicação web moderna desenvolvida com Nuxt 3, TypeScript e DaisyUI, demonstrando boas práticas de desenvolvimento e padrões de projeto. O foco principal é criar uma interface intuitiva e responsiva, utilizando componentes reutilizáveis e mantendo um código limpo e bem organizado.

A aplicação inclui recursos como autenticação, gerenciamento de usuários, perfis personalizados e um sistema completo de configurações.

## Technologies Used

- **Nuxt 3**: Framework Vue.js para criação de aplicações web modernas
- **TypeScript**: Adiciona tipagem estática ao JavaScript
- **DaisyUI**: Componentes de UI baseados em Tailwind CSS
- **Tailwind CSS**: Framework CSS utilitário
- **Vue.js**: Framework JavaScript progressivo
- **PrimeIcons**: Biblioteca de ícones

## Features

- 🔐 Autenticação de usuários
- 👤 Gerenciamento de perfil
- ⚙️ Sistema de configurações
- 📱 Design responsivo
- 🎨 Temas personalizáveis
- 🔍 Pesquisa e filtragem
- 📊 Dashboard interativo

## Getting Started

### Prerequisites

- Node.js 16.x ou superior
- npm ou yarn

### Installation

```bash
# Clone o repositório
git clone https://github.com/ruanvalente/daisy-ui-nuxt.git

# Entre no diretório
cd daisy-ui-nuxt

# Instale as dependências
npm install
# ou
yarn install
```

### Development

```bash
# Inicie o servidor de desenvolvimento
npm run dev
# ou
yarn dev
```

O aplicativo estará disponível em `http://localhost:3000`

### Production

```bash
# Build para produção
npm run build
# ou
yarn build

# Preview do build
npm run preview
# ou
yarn preview
```

## Project Structure

├── public/             # Arquivos estáticos
├── composables/        # Composables Vue
├── types/              # Definições de tipos TypeScript
└── utils/              # Funções utilitárias
```
